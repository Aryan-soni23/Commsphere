# 📱 Commsphere — Android Chat App

Commsphere is a real-time Android chat application built using Java and CometChat SDK, supporting messaging, voice/video calls, and group communication.

---

## 🚀 Features

- 💬 Real-time messaging (1–1 & groups)  
- 📞 Voice & video calling (WebRTC)  
- 👥 User & group management  
- 🎨 Material UI with dark mode  
- 🔐 Secure authentication  

---

## 🛠 Tech Stack

- Java (Android)  
- CometChat UI Kit & Calls SDK  
- Material Design 3  
- Glide, ConstraintLayout  

---

## 📊 Highlights

- ⚡ ~150ms message delivery  
- 📦 24.5MB APK size  
- 📈 99.98% uptime  
- ⭐ 4.7/5 user rating
